# 🎨 DesignFlow — Web-based Design Editor (Canva-like)

A graphical, component-driven design editor for creating beautiful layouts, illustrations and marketing assets in the browser — inspired by pixel-perfect visual tools.

---

## ✨ Highlights

- Drag & drop canvas with snapping & alignment guides
- Layered editing (arrange, lock, hide)
- Reusable component library (cards, buttons, frames)
- Templates & presets to jumpstart designs
- Export to PNG / JPG / SVG
- Smooth transitions, animations & visual polish
- Keyboard shortcuts, undo/redo, and responsive previews

## ⚙️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/nitin01924/DesignFlow.git
cd DesignFlow
```

### 2. Setup Backend (if present)

```bash
cd Backend
npm install
```

Create a `.env` file inside Backend (example):

```
PORT=3000
# Add any other backend env vars your project requires (DB, API keys, JWT secret)
```

Run backend:

```bash
npm run dev
```

### 3. Setup Frontend

```bash
cd Frontend
npm install
```

Create a `.env` file inside Frontend (example):

```
VITE_API_URL=http://localhost:3000/api
```

Run frontend (development):

```bash
npm run dev
```

Build (production):

```bash
npm run build
```
